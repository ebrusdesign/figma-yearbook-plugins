Yearbook Photo Fill

Fills empty photo frames with justified, uncropped photos.

1. Frames none selected
Select the empty PHOTO PAGE frames (or whole book pages) in Figma, in any order — they're filled left-to-right, top-to-bottom.
2. Photos none yet
Choosing a folder replaces what's loaded and uses only its READY photos (BACKUPS and NEEDS REVIEW are ignored).

Proof check duplicates & print issues
Scans every photo in the file — including ones placed by hand — for repeats, look-alikes, low resolution, heavy crops and empty photo frames. Nothing is changed.
